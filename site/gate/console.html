接入方式（发给各部门开发者）

agent 携带所属部门签发的 token 调用网关求值；网关按部门策略裁决，逐笔写入哈希链审计：

POST https://gate.paycensus.com/api/gate/evaluate
Authorization: Bearer gk_xxxx…
{"resource": "https://merchant.example/api", "amountUsd": 0.008,
 "rail": "x402", "payTo": "0x…"}

→ 200 {"agent": "sales-bot-01", "dept": "销售部",
       "decision": {"allow": true, "status": "auto-approved",
                    "reason": "…", "eventHash": "…"}}

决策语义：allow=true 才付款；pending 需管理员在审计面板批准后重试；拒绝即停。token 泄漏可随时吊销（吊销立即生效）。
