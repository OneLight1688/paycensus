GET /api/status?addr={address}

curl "https://trust.paycensus.com/api/status?addr=0x1603B3A5119AA82AB1349E29f2d49B5170e085b7"

Response:

{ "addr": "0x1603…85b7", "domain": "seller.example.com", "status": "verified", "verified_at": "2026-11-07 03:40:11 UTC", "last_checked": "2026-11-07 03:40:11 UTC", "since": "2026-11-07" }

status ∈ verified · pending · revoked · none. Cached ≤60s. Revoked records keep history — see /api/revocations.

GET /api/revocations

Public append-only revocation list (the CRL of machine commerce). Cached ≤60s.

POST /api/verify/start · /api/verify/check · /api/report

Seller-side flows — used by the verify page; same contract. A report triggers an automatic re-examination; the deterministic result is the outcome. Reports are logged append-only.

GET /api/factors?addr={address}

Metered factor lookup — the endpoint a facilitator or agent calls before settling. 10 calls/day free per key. v0.3: cross-data-layer factors included.

curl "https://trust.paycensus.com/api/factors?addr=0x1603B3A5119AA82AB1349E29f2d49B5170e085b7" \ -H "Authorization: Bearer pct_live_…"

Response:

{ "addr": "0x1603…85b7", "status": "verified", "domain": "seller.example.com", "since": "2026-11-07", "last_checked": "2026-11-07 13:41:08 UTC", "plan": "free", "calls_today": 1, "limit": 10, "factors": { "attribution": {"domain": "seller.example.com", "title": "…", "source": "enrich_v3", "first_seen": "2026-11-01"}, "onchain": {"volume_usd": 1234.5, "txs": 89, "chains": 1, "first_day": "2026-11-01", "volume_percentile": 72.4}, "offers": {"offer_consistency": "stable", "count": 1, "protocols": ["x402"], "latest_usd": 0.05}, "contactability": {"channel": true, "note": "public role-contact exists; content is never published"} } }

factors may be null where the data layer has no record — absence is reported as absence, never guessed. HTTP 429 when the daily quota is exhausted. Composite scoring deliberately does not exist yet: factors before scores, always.
