Usage rules — short version

  1. Only entities with active verification may display the badge; remove it if verification lapses or is revoked.
  2. Do not alter, recolor, crop or animate the badge.
  3. Link the badge to verify.html (the live widget does this automatically).
  4. The live status page is always authoritative over any static image.

Full rules in the pack README. Verification states facts, not opinions — see the terms.
